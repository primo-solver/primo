Primo SMT solver scaffold


primo [OPTIONS] [files...]


POSITIONALS:
  files FILE ...              SMT-LIB input files. Reads stdin when omitted

Procedural options:
  -h,     --help              Print this help message and exit
          --check-model       Check original assertions against produced typed models
  -q,     --quiet [default: off]
                              Suppress startup version banner
          --stats [default: off]
                              Print solver statistics to stderr
          --preprocess-only [default: off]
                              Diagnostic: stop before search; report unsat if preprocessing
                              refutes, otherwise unknown. Quantified input stops after the
                              frontend
          --cancel-grace-seconds UINT:UINT in [1 - 3600] [1]
                              Seconds SIGTERM or SIGINT waits for the cooperative cancellation
                              path, which reports statistics, before answering unknown and
                              exiting
          --version           Display program version information and exit

Experimental tactic options:
          --experimental-split-bools UINT:INT in [0 - 16] [0]
                              EXPERIMENTAL: split on up to k Boolean atoms, materialize 2^k
                              disjunctive goals, and solve them sequentially in false-first
                              order; 0 disables
          --experimental-generic-model-combination [default: off]
                              Route QF_UFLRA shared-model decisions through the generic
                              sequential coordinator

QF_LRA theory options:
          --lra-propagation [default: on]
                              Enable QF_LRA same-slack bound propagation (Milestone 3b)
          --no-lra-propagation [default: off]
                              Disable QF_LRA bound propagation (conflict detection only)
          --lra-row-propagation [default: off]
                              Enable experimental QF_LRA row-based/interval bound propagation
                              across different variables (only takes effect if
                              --lra-propagation is also on)
          --lra-bidirectional-row-propagation [default: off]
                              Enable the reverse direction of --lra-row-propagation: tighten a
                              row's other terms from its own bound, not just derive the row's
                              own implied bound (only takes effect if --lra-row-propagation is
                              also on)
          --lra-row-propagation-max-row-size UINT:POSITIVE [64]
                              Cap on the row length --lra-row-propagation will derive an
                              implied bound for. Rows longer than this are skipped, not
                              truncated
          --lra-row-propagation-max-fanout UINT:POSITIVE [64]
                              Cap on how many rows a single bound change may trigger a
                              --lra-row-propagation scan over. A variable occurring in more
                              rows than this propagates nothing that round
          --lra-bidirectional-row-propagation-max-row-size UINT:POSITIVE [32]
                              Row-length cap for the reverse direction
                              (--lra-bidirectional-row-propagation). Smaller than the forward
                              cap because that direction costs O(row size) per other term, not
                              per row
          --lra-bidirectional-row-propagation-max-fanout UINT:POSITIVE [32]
                              Fanout cap for the reverse direction
                              (--lra-bidirectional-row-propagation)
          --lra-theory-decisions [default: off]
                              Enable experimental QF_LRA theory-guided decisions: the
                              arithmetic theory ranks candidate atoms via CaDiCaL's cb_decide
                              and supplies the decision literal itself instead of leaving every
                              decision to generic VSIDS
          --lra-equality-propagation [default: off]
                              Enable experimental pure QF_LRA model-unit equality discovery and
                              propagation of existing difference comparisons (IPASIR-UP only)
          --lra-model-phase [default: auto]
                              Enable model-based SAT phase hints (automatic for QF_LRA rebuild
                              queries with auto preprocessing): keep CaDiCaL's variable choice,
                              but refresh arithmetic atom polarity from the current tableau
                              assignment at quiescence points
          --no-lra-model-phase [default: off]
                              Disable model-based SAT phase hints
          --lra-pivoting-rule TEXT:{bland,dantzig,soi,sparse} [sparse]
                              QF_LRA Check/Pivot variable-selection rule: sparse (prices what a
                              pivot costs: among the entering candidates that all repair the
                              violation equally, take the one occurring in the fewest rows,
                              since those are exactly the rows the pivot rewrites), bland
                              (anti-cycling-proven), dantzig
                              (largest-violation/largest-coefficient), or soi
                              (Sum-of-Infeasibilities Simplex, King/Barrett/Dutertre FMCAD 2013
                              -- a global Check/Pivot objective across every violated row at
                              once). All but bland fall back to bland selection after enough
                              pivots within one check(), which is what keeps termination proven
          --lra-least-violated-leaving [default: off]
                              Experimental leaving-variable rule from Griggio's thesis (2.5.3,
                              p.53):
                              pick the LEAST-violated basic variable, tie-broken by the shorter
                              row.
                              Only meaningful under --lra-pivoting-rule sparse
          --no-lra-sparse-leaving [default: off]
                              Disable the leaving-side half of --lra-pivoting-rule sparse
                              (prefer repairing a violated variable whose row is short, using
                              violation magnitude only as a tie-break), for ablation
          --lra-sparse-pricing-candidates UINT:INT in [0 - 1000000] [16]
                              How many eligible entering candidates --lra-pivoting-rule sparse
                              scores before taking the best seen so far (0 means score every
                              eligible candidate). 1 is the cheapest possible pricing. Never
                              cuts short the search for whether an eligible candidate exists,
                              so any value is sound
          --lra-soi-minimize TEXT:{quickxplain,deletion,none} [quickxplain]
                              How --lra-pivoting-rule soi shrinks a multi-row conflict before
                              turning it into a clause: quickxplain (Junker 2001), deletion
                              (iterative, and steerable by --lra-soi-minimize-order), or none
                              (ablation baseline). Inert under every other pivoting rule.
                              Measured, the error set averages 2.83 variables and never
                              exceeded 9, so this changes which minimal conflict is learned
                              rather than how fast it is found
          --lra-soi-minimize-order TEXT:{id,row-support,violation} [id]
                              Order --lra-soi-minimize deletion offers candidates for removal,
                              worst first: id (ascending, reproduces quickxplain's input
                              order), row-support (longest row first -- the row support
                              dominates clause length, so this sheds the rows contributing most
                              literals), or violation (largest bound violation first)
          --lra-bland-fallback-factor UINT:INT in [0 - 1000000] [4]
                              Per-variable coefficient of check()'s Bland's-rule fallback
                              point, which is factor * variables + offset pivots within one
                              check. Smaller switches to Bland's rule sooner: slower but
                              anti-cycling-proven
          --lra-bland-fallback-offset UINT:INT in [0 - 1000000000] [64]
                              Constant term of the Bland's-rule fallback point
          --mixed-dispatch TEXT:{narrow,wide} [narrow]
                              Which formulas reach the mixed EUF/LRA solver: narrow (only a
                              Bool-sorted function APPLICATION counts as an EUF predicate, so a
                              formula that is pure QF_LRA apart from propositional variables
                              stays on the pure path) or wide (a Bool-sorted constant counts
                              too -- the pre-2026-08-07 behaviour, routing any QF_LRA formula
                              containing one propositional variable to the mixed solver).
                              Usually much worse, but genuinely better on some instances; kept
                              as a portfolio dimension and so differential fuzzing can reach
                              the mixed path
          --lra-fixed-elimination [default: off]
                              Pivot a basic LRA variable out of the basis as soon as its bounds
                              coincide (heuristics item H7). It nets to nothing on the
                              scrambled competition set, but doubles the >5MB band, so it is
                              worth enabling on equality-dominated input
          --no-qf-uflra-fixed-elimination [default: off]
                              Disable mixed QF_UFLRA fixed-variable elimination, which exposes
                              EqRow interface equalities before the exact pair fallback
          --gaussian-elimination [default: on]
                              Enable QF_LRA Gauss-Jordan elimination over asserted linear
                              equality systems, feeding solve-eqs (campaign-fuzzed 2026-07-25)
          --no-gaussian-elimination [default: off]
                              Disable QF_LRA Gauss-Jordan equality-system elimination
          --qf-uflra-candidate-final-scan [default: off]
                              Enable experimental mixed QF_UFLRA candidate-first final LRA
                              equality scans before falling back to the full shared-Real pair
                              scan
          --qf-uflra-lra-equality-producer TEXT:{legacy,model-unit,adaptive} [legacy]
                              LRA-to-EUF opportunistic equality producer: legacy exact-offset
                              row indexes or model-unit current-model-filtered unit rows;
                              adaptive bootstraps legacy to a propagation fixed point, then
                              uses model-unit until a later shared-model split
          --qf-uflra-model-reconciliation [default: on]
                              Explicitly enable convex QF_UFLRA shared-model reconciliation
                              with scratch LRA mutation, EUF compatibility checks, and lazy
                              positive equality splits
          --no-qf-uflra-model-reconciliation [default: off]
                              Disable convex QF_UFLRA shared-model reconciliation and use the
                              explained exact equality-sharing fallback
          --monotone-elimination [default: auto]
                              Enable monotone (one-sided) real-variable elimination (automatic
                              for
                              QF_LRA rebuild queries with auto preprocessing): a
                              variable every constraint pushes the same way is discharged and
                              its
                              atoms folded to constants, shrinking the Boolean structure.
                              Models are
                              reconstructed for eliminated variables
          --no-monotone-elimination [default: off]
                              Disable monotone real-variable elimination
          --guarded-real-equality-lowering [default: off]
                              Enable experimental guarded Real equality lowering: rewrite a
                              disjunction with one Real equality child directly to two guarded
                              inequalities, avoiding one Tseitin layer on some QF_LRA encodings
